WEBSITE UNICEF INDONESIA (Zia) (tugas kuliah)
Prefix class dan id: zianarah_

CARA PAKAI
1. Ekstrak zip, buka index.html di browser.
2. Jalankan: python unduh-gambar.py (mengunduh semua gambar otomatis ke img/). Atau taruh manual dengan nama persis (format .webp):
   logo-unicef, logo-unicef-putih, hero-beranda, kartu-gaza, kartu-champions,
   cerita-anak-penggerak, cerita-margaretha, cerita-ayah-imunisasi,
   pers-el-nino, pers-young-health, pers-thomas-davin, banner-ambil-bagian,
   banner-upaya, kartu-penelitian, kartu-cerita, kartu-ambil-bagian,
   hero-faq, hero-kontak, kartu-pusat-pers
   (sebelum gambar ada, kotak gambar tampil sebagai placeholder kuning)
3. Buka js/script.js, ganti zianarah_email_pemilik di baris atas dengan emailmu,
   supaya tombol "Kirim lewat email" di form kontak mengarah ke emailmu.

HALAMAN: index, upaya, penelitian, cerita, ambil-bagian, tentang, pusat-pers, kontak
